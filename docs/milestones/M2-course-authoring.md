# M2: Course Authoring

## Outcome

Teacher builds reusable course curriculum quickly.

## Scope

- Courses, modules, canonical items, placements, resources.
- Reorder modules/items with accessible controls.
- Markdown/HTML editor, preview, import, sanitizer.
- Draft/published items.
- Outline parser, editable preview, atomic import.
- Multiple module placements without content duplication.

## Acceptance

- Teacher creates full empty syllabus in one outline flow.
- Same item appears in multiple modules and edits once.
- Unsafe HTML payloads do not execute.
- Other users cannot read templates.
