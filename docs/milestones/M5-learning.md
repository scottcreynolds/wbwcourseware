# M5: Learning Experience and PDF Views

## Outcome

Students navigate released curriculum and export readable pages.

## Scope

- Student cohort/module/item navigation.
- Released/published filters enforced by RLS.
- Ordered resources and safe external links.
- Branded print routes/layouts.
- Empty/locked/not-found states.

## Acceptance

- Student sees only released modules and published items.
- Draft/direct-link access is denied.
- Print view includes header, content, resources, and due date where relevant.
- Keyboard/mobile/zoom behavior passes core checks.
