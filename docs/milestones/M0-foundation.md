# M0: Foundation

## Outcome

Runnable Vue app and local Supabase stack with quality gates.

## Scope

- Scaffold Vue/Vite/Vuetify/TypeScript with `pnpm`.
- Add router, app layouts, error boundary strategy, environment validation.
- Initialize Supabase local config and deterministic seed.
- Add Vitest, Vue Test Utils, Playwright, lint, formatting, typecheck.
- Add CI running non-secret checks.
- Add Mailpit-compatible local email configuration/documentation.

## Acceptance

- Fresh documented setup starts app and local services.
- Teacher/student placeholder routes render accessibly.
- `pnpm verify` passes.
- No production deployment.
