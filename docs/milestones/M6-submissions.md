# M6: Submissions

## Outcome

Students submit workshop PDFs and read cohort submissions; teacher sees status.

## Scope

- Private bucket, upload intents, finalize flow.
- PDF/25 MB validation at multiple layers.
- Immutable multi-file versions and late labels.
- Cohort peer submission listing/download authorization.
- Teacher missing/on-time/late dashboard.

## Acceptance

- Resubmission creates next version without changing prior version.
- Active peers can read immediately.
- Other cohorts and removed users cannot access metadata or files.
- Abandoned/failed uploads do not create visible submission versions.
