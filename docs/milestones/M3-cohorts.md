# M3: Cohorts and Curriculum Snapshots

## Outcome

Teacher creates scheduled cohort instance from course.

## Scope

- Cohort schema/status/dates/timezone.
- Atomic curriculum snapshot.
- Cohort assignment due dates.
- Manual and scheduled module release.
- Apply course item changes to selected cohorts.

## Acceptance

- Snapshot preserves structure and multi-module placements.
- Student visibility predicate handles release and draft status.
- Sync preserves cohort-only fields.
- Concurrent/failed copy cannot create partial cohort.
