# M1: Authentication and Roles

## Outcome

Secure teacher login/bootstrap and student auth foundations.

## Scope

- Profiles/global role schema and RLS.
- Login/logout/password reset/verification states.
- Idempotent teacher bootstrap path.
- Role-based application shells and route UX.
- Prevent public role selection and role mutation.

## Acceptance

- Bootstrapped teacher reaches teacher shell.
- Uninvited signup gains no cohort access.
- Direct API role escalation fails.
- Auth recovery paths tested.
